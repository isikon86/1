# vorp_psychology

Отдельный ресурс психики. Стресс добавляется событием `vorp_psychology:addStress`; ресурс зомби может вызывать `vorp_psychology:zombieNearby` с `true`. Восстановление предметами — событиями `vorp_psychology:useCoffee` и `vorp_psychology:useCigarette`. Ресурс сна вызывает восстановление после сна через событие `vorp_psychology:recoverFromRest`.
