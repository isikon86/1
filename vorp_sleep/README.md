# VORP Sleep

Система сна, дремоты и взаимодействия с мебелью для RedM/VORP.

## Управление

- `E` — сесть или удерживать для того, чтобы лечь.
- `X` — встать или прервать взаимодействие.
- `/sitdebug` — включить отладку ближайших объектов.
- `/sitnearby` — вывести ближайшие объекты в консоль.
- `/sitstatus` — показать текущее состояние.
- `/stand` — принудительно встать.

## Настройка

Модели мебели и сценарии находятся в `config.lua`. Ресурс использует автоматический поиск объектов и не требует координат. После полного времени сна сервер вызывает восстановление сна и психики.

Технические имена событий и моделей оставлены без перевода, поскольку они используются кодом RedM.
