# vorp_sleep

Ресурс автоматически находит стандартные модели кроватей и костров, поэтому координаты в `config.lua` не нужны. Списки моделей находятся в `Config.BedModels` и `Config.CampfireModels`. Для проверки неизвестного объекта рядом с игроком доступна команда `/sleep_object`. Если `vorp_psychology` запущен, сон также восстанавливает психику.
